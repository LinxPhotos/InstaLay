= Tapestry drag repaint performance

* Photo drafts bake sibling default placements in one pass on drag start so unplaced photos no longer stack at the origin during drag.
* Skip redundant `EditorScreen` selection rebuild when dragging an already-selected layer; batch reorder skips layout/photo select when unchanged.
* Tapestry canvas subtree uses `ExcludeSemantics` + `Focus(includeSemantics: false)` to reduce Windows `accessibility_bridge` AXTree spam during drag.
* Arrow-key nudges use the local draft + debounced parent commit.
