= Canvas overflow pan & batch reorder

== User-visible

* Batch and tapestry layout previews share a horizontal viewport with a visible scrollbar and wheel / trackpad pan when content is wider than the cell.
* Batch photos reorder on desktop via click-drag; on mobile via long-press then slide (touch scroll still works when not reordering).
* Tapestry on touch: tap selects a layer first; drag moves only after selection so finger scrolling the strip stays available.

== Implementation

* New `HorizontalCanvasViewport` replaces ad-hoc horizontal `SingleChildScrollView` in batch/tapestry cells.
* Batch reorder extracted to `InteractiveBatchStrip` (was inline in `canvas_workspace.dart`).
* Tests: `canvas_horizontal_viewport_test.dart`, `batch_photo_reorder_test.dart`.
